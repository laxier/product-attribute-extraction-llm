# Извлечение атрибутов товаров с помощью LLM

Проект ВКР: извлечение семи атрибутов мониторов из русскоязычных описаний — диагонали, разрешения, частоты обновления, типа матрицы, яркости, контрастности и изогнутости.

Модель получает описание и возвращает JSON: явно указанные значения или `null`, если характеристика отсутствует. Таблица характеристик магазина используется только для подготовки эталона.

## Цель и задачи

Цель — реализовать и экспериментально оценить конвейер извлечения семи атрибутов мониторов, выбрать конфигурацию по заранее заданному протоколу и проверить её на данных DNS и М.Видео.

Объект исследования — извлечение структурированной информации из текстовых описаний товаров. Предмет — извлечение и нормализация атрибутов открытыми LLM в режимах zero-shot и few-shot с ограничением JSON-вывода.

Задачи:

1. Изучить методы извлечения атрибутов и сформулировать гипотезы.
2. Подготовить карточки DNS и М.Видео, сформировать и проверить эталон.
3. Создать синтетические примеры и протокол сравнения восьми открытых LLM.
4. Провести пилот, сравнить модели и выбрать конфигурацию на DNS `real-val`.
5. Однократно оценить её на DNS `real-test` и проверить перенос на М.Видео без настройки.
6. Дополнительно оценить качество, память обучения и перенос QLoRA-адаптеров.

## Гипотезы

| Гипотеза | Проверяемое утверждение |
|---|---|
| H1 | Выбранная конфигурация на DNS `real-test` достигает нормализованного micro-F1 ≥ 0,90, доли ложных значений на `null` ≤ 0,10 и доли невалидных ответов < 1 %. |
| H2 | Few-shot повышает micro-F1 минимум на 0,02 относительно zero-shot; парный 95%-й bootstrap-интервал прироста не включает ноль. |
| H3 | JSON-схема снижает долю невалидных ответов ниже 1 % при потере micro-F1 не более 0,02. |
| H4 | Ошибки формата — наиболее частый тип ошибок; нормализация повышает micro-F1 минимум на 0,02. |
| H5 | QLoRA повышает micro-F1 на DNS `real-val` относительно лучшего базового режима той же модели; 95%-й интервал парного прироста выше нуля. |
| H6 | Пиковая выделенная GPU-память при обучении адаптера не превышает 16 ГБ. |
| H7 | Прирост QLoRA сохраняется на М.Видео без повторной настройки: 95%-й интервал парного прироста micro-F1 выше нуля у всех восьми моделей. |

H1–H4 — основные гипотезы; H5–H7 относятся к дополнительному эксперименту и не влияют на выбор основной конфигурации. DNS используется для пилота, выбора и итоговой оценки, М.Видео — для проверки переноса. Данные второго источника не используются для настройки.

## Запуск

Python 3.10+:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Зависимости сейчас предназначены для анализа данных и ноутбуков. Окружения запуска моделей и обучения будут описаны на соответствующих этапах.

## Данные и публикация

В репозитории размещаются код, методика, проверенные конфигурации, manifests и агрегированные результаты. Исходные карточки, построчные ответы моделей, локальные эталоны, веса, адаптеры и секреты хранятся локально. Сборщики, рабочие документы и архивные эксперименты в публичную часть не входят.
