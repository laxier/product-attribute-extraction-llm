# Выбор моделей для будущего сравнения

Для следующего этапа отобраны восемь моделей с открытыми весами из исследовательского протокола проекта. Страницы разработчиков проверены 5 ноября 2026 года. На этом этапе модели не запускались: таблица фиксирует основания выбора, а не рейтинг качества.

## Критерии включения

Доступные веса и instruct-режим; возможность передать русскоязычное описание и получить текстовый ответ; разнообразие семейств; разные размеры и организация вычислений; возможность дальнейшего запуска в ограниченной памяти. Планируется оценить четыре режима: zero-shot/few-shot × свободный JSON/JSON-схема. Совместимость квантизации и ограничения лицензии нужно проверить перед запуском каждой конкретной конфигурации.

## Что проверять далее

До сравнительных запусков необходимо зафиксировать версии весов, токенизаторов и библиотек, точный формат диалога, настройки генерации и среду исполнения. Для всех кандидатов используется только текст, даже если модель поддерживает другие модальности. Само наличие весов не гарантирует, что все восемь моделей поместятся в одинаковую видеопамять при одинаковой квантизации.

Качество предполагается оценивать по корректности семи значений, ошибочным ненулевым ответам при отсутствии упоминания и доле валидного JSON. Время и пиковая память измеряются отдельно. Никакая модель здесь не объявляется лучшей: это можно установить лишь после единого воспроизводимого эксперимента.

Тестовые 20 карточек из `split_manifest.json` остаются отложенными. Для настройки инструкции и few-shot примеров допустимы только development-записи, причём few-shot примеры должны иметь проверенные вручную ответы.
