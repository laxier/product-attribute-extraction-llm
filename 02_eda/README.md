# Пилотная подготовка данных

Этап ограничен **50 карточками мониторов DNS** из локального файла `dns_cards_50.json`. Это отдельная пилотная выборка, а не первые 50 записей основного набора из 500 карточек. Здесь проверяется качество данных и формируется список моделей для следующего этапа.

Одна запись содержит `url`, `code`, `title`, `category`, `description` и словарь `specs`. Целевые атрибуты дальнейшего извлечения: диагональ, разрешение, частота обновления, тип матрицы, яркость, контрастность, изогнутость.

## Проверка пилота

В исходном порядке отбираются первые 50 записей с `specs["Тип"] == "монитор"`. Проверяются пустые поля, повторы URL, кода товара и нормализованного описания. Пробельные последовательности в описаниях приводятся к одному пробелу. Первые 30 очищенных записей выделены для разработки, последние 20 — для последующей проверки. Тестовые 20 записей нельзя использовать как примеры в запросах или для настройки инструкций.

По текущему файлу:

- все 50 записей относятся к мониторам; пустых основных полей и точных повторов не найдено;
- нормализованы описания в 40 карточках, удалённых записей нет;
- длина нормализованного описания — 313–1257 символов, медиана 872;
- представлены 12 брендов;
- в двух таблицах характеристик нет значения ключа `Максимальная частота обновления экрана`.

Справочные характеристики `specs` не являются готовой разметкой извлечения из текста: значение допустимо выдавать, только если оно явно присутствует в описании. Покрытие упоминаний и корректный возврат `null` требуют отдельной ручной разметки.

## Материалы

- `results/pilot_summary.json` — агрегированные результаты проверки без исходных описаний.
- `results/split_manifest.json` — ссылки на карточки, разбиение 30/20 и SHA-256 исходного JSON.
- [Выбор моделей](docs/model_selection.md) — кандидаты и основания включения; без результатов сравнения.

Локальный код подготовки находится в `src/` и исключён из Git. Исходные тексты карточек и файл данных для сдачи лабораторной хранятся локально. Публичный репозиторий содержит методику, ссылки и агрегаты. Команды воспроизведения для локальной копии приведены в `src/LOCAL_RUN.md`.

Полный EDA, сравнение ответов языковых моделей и дообучение в рамках этого этапа не выполнялись. Пилот из 50 записей и его неслучайное разбиение недостаточны для выводов о качестве на всём каталоге.
