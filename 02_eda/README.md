# Пилотная подготовка данных

Этап работает с **50 карточками мониторов DNS** из локального файла `dns_cards_50.json`. Это отдельная пилотная выборка, а не первые 50 записей основного набора. Цель этапа — проверить качество входных данных, подготовить предварительные пары «атрибут — значение» и зафиксировать выбор моделей для следующего этапа.

Ожидаемая запись содержит `url`, `code`, `title`, `category`, `description` и словарь `specs`. Для извлечения проверяются семь атрибутов: диагональ, разрешение, частота обновления, тип матрицы, яркость, контрастность и изогнутость.

## Пайплайн

`src/pilot_eda.py`:

1. загружает JSON-массив и оставляет записи с `specs["Тип"] == "монитор"`;
2. нормализует пробелы в описаниях;
3. ищет почти полные дубликаты описаний с помощью TF-IDF по символьным n-граммам и cosine similarity (`>= 0.97`);
4. сопоставляет значения из `specs` с явными упоминаниями в описании;
5. строит предварительные эталонные значения только для совпадений, а отсутствующие упоминания оставляет как `null`;
6. сохраняет сводку, manifest разбиения, пары атрибутов и график покрытия.

По зафиксированному пилотному запуску: 50 записей относятся к мониторам, пустых основных полей и удалённых дубликатов нет, описания нормализованы в 40 карточках. Длина описаний после нормализации — 313–1257 символов, медиана — 872; представлены 12 брендов. В двух карточках отсутствует значение `Максимальная частота обновления экрана` в `specs`.

Справочные характеристики `specs` не являются полной ручной разметкой извлечения из текста. Совпадения требуют проверки, а для случаев без явного упоминания нужно сохранить `null`. Поэтому автоматически полученные пары используются как черновая основа для ручной верификации.

## Результаты

- `results/pilot_summary.json` — агрегированная сводка без исходных описаний;
- `results/split_manifest.json` — SHA-256 входного JSON, правило разбиения и ссылки на карточки;
- `results/gold_pairs.csv` — предварительные пары атрибутов, генерируются локально и не публикуются;
- `results/coverage_stacked.png` — график покрытия упоминаний атрибутов, генерируется локально;
- [Выбор моделей](docs/model_selection.md) — кандидаты и основания включения без результатов сравнения.

Исходные тексты карточек, сгенерированный `*_gold.json` и локальные CSV-результаты не входят в публичную часть репозитория. Команды воспроизведения для локальной копии приведены в [LOCAL_RUN.md](src/LOCAL_RUN.md). Скрипт требует Python 3.10+ и пакеты из корневого `requirements.txt`.
