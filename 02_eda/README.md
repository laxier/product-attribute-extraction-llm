# EDA и подготовка эталона DNS

Цель этапа — проанализировать карточки мониторов, сформировать кандидат эталона и разделить данные для экспериментов.

## Данные и разбиение

Из 500 исходных карточек DNS оставлены **494 монитора**; 6 карточек других типов исключены. Почти полных дубликатов описаний с cosine similarity ≥ 0,97 не найдено. Длина исходных описаний — 219–1585 символов, медиана — 784,5; представлены 28 брендов.

| Выборка | Карточек | Назначение |
|---|---:|---|
| `pilot` | 100 | Проверка процедур и фиксация порогов |
| `real_val` | 158 | Сравнение моделей и выбор конфигурации |
| `real_test` | 236 | Однократная итоговая оценка |

Первые 100 карточек после дедупликации образуют пилот. Остаток перемешивается с seed 42 и делится в отношении 40/60 с округлением размера `real_val`. Состав выборок зафиксирован в `results/split_manifest.json`. Исключения перед финальным прогоном описываются отдельно на этапе `08_real_test_run/`; здесь сохраняются все 236 идентификаторов теста.

## Подготовка эталона

`src/pilot_eda.py` читает JSON-массив с полями `url`, `code`, `title`, `category`, `description`, `specs`, оставляет записи с `specs["Тип"] == "монитор"` и ищет дубликаты через TF-IDF символьных n-грамм (3–5).

Для семи атрибутов значение из таблицы сопоставляется с упоминаниями в описании:

- значение явно названо и совпадает с таблицей — оно попадает в кандидат эталона;
- упоминания нет или найдено другое значение — сохраняется `null`;
- характеристики нет в таблице — пара пропускается, как в исходном эксперименте; отсутствие справочного значения не считается отсутствием упоминания.

Например, название «Full HD» без числового разрешения не засчитывается как `1920x1080`. Нормализация пробелов применяется при сохранении описаний; правила поиска и состав эталона сохранены из эксперимента ВКР.

Получено **3427 пар «карточка — атрибут»**. В 23 карточках автоматическая проверка обнаружила хотя бы одно расхождение с таблицей. Это кандидаты на проверку, а не итог ручного аудита. Эталон сформирован автоматически и требует ручной верификации; таблица магазина не считается безошибочной разметкой текста.
