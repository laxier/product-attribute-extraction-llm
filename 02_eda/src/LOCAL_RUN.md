# Локальное воспроизведение EDA

Python 3.10+, зависимости из корневого `requirements.txt`: pandas, matplotlib и scikit-learn. Модели и GPU не нужны.

Из корня репозитория создайте окружение и поместите исходные 500 карточек DNS в `data/dns_cards_500.json`. Исходные данные не включены в репозиторий и автоматически не скачиваются.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python 02_eda/src/pilot_eda.py \
  --input data/dns_cards_500.json \
  --out-dir 02_eda/results \
  --private-dir data/eda
```

Для основного корпуса команда воспроизводит разбиение ВКР. При другом входном файле укажите другой `--out-dir`, чтобы сохранить основные результаты. SHA-256 исходного файла записывается в сводку и manifest для указания использованной версии данных.

В `02_eda/results/` сохраняются агрегированная сводка `eda_summary.json`, состав выборок `split_manifest.json` и график `coverage_stacked.png`. Версии Python и библиотек записываются в сводку; при другом окружении файл сводки может отличаться этими полями.

Локальные `gold_pairs.csv` и `dns_cards_500_gold.json` сохраняются в `data/eda/`, отдельно от публичных результатов. Исходный JSON и исторический эталон в рабочем проекте не изменяются. В эталон входят только карточки после фильтрации и дедупликации.

Разбиение фиксировано: первые 100 карточек после дедупликации — `pilot`; остаток перемешивается через `pandas.DataFrame.sample(random_state=42)`, затем 40 % с округлением — `real_val`, остальные — `real_test`.
