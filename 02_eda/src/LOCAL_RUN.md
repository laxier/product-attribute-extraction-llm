# Локальное воспроизведение

Из корня `02_eda`:

```bash
python3 src/pilot_eda.py \
  --input '/Users/kirill/Desktop/ВКР/vkr1_attributes/data/dns_cards_50.json' \
  --out-dir results
```

Требуется Python 3.10+, внешние зависимости не нужны. Код не загружает модели и не выгружает исходные описания. Для другого входного файла результаты и состав выборки могут отличаться; SHA-256 фиксируется в сводке. Если после очистки остаётся меньше 50 карточек, скрипт завершится с ошибкой вместо незаметной замены состава выборки.
