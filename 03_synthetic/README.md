# Синтетические данные

`src/generate.py` генерирует описания мониторов через Claude по заранее заданным атрибутам. Стиль, значения и частоты упоминаний берутся только из пилота DNS. Тексты проверяются на соответствие эталону и копирование фраз из образцов.

## Запуск

Установите зависимости из корневого `requirements.txt` и задайте `ANTHROPIC_API_KEY` в окружении или `.env` в корне проекта. Генерация использует платный API.

После подготовки EDA выполните из корня репозитория:

```bash
python 03_synthetic/src/generate.py fewshot 20 1
python 03_synthetic/src/generate.py train 1000 3
python 03_synthetic/src/generate.py train_names 200 4
```

Аргументы: имя набора, итоговое число описаний, seed. `fewshot` — примеры для запроса; `train` и `train_names` — данные для QLoRA. В `train_names` разрешение называется словом, примерно в половине случаев без цифр — тогда эталон `null`.

Скрипт читает `data/dns_cards_500.json`, `data/eda/gold_pairs.csv` и `02_eda/results/split_manifest.json`. Результаты сохраняются локально в `data/synthetic/<имя>.jsonl` и не публикуются. Повторный запуск дополняет набор; используйте те же seed, модель и входные данные.

## Результаты генерации

| Набор | Описаний | Назначение |
|---|---:|---|
| `fewshot` | 20 | Примеры для запросов |
| `train` | 1000 | Основная обучающая выборка |
| `train_names` | 200 | Дополнение с названиями разрешения; 98 примеров без цифр с эталоном `null` |

Всего для QLoRA подготовлено 1200 описаний; 20 few-shot-примеров хранятся отдельно. [Манифест наборов](results/manifest.json) содержит объёмы, назначение и пути к файлам. Сами JSONL остаются локальными.
